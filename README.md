# שיבוץ מדריכים – נוער שוחר מדע

אתר לשיבוץ מדריכים לימי עיון, קורסים, הרצאות ומופעי קסמים. האתר קורא את שני הקבצים שכבר יש לכם, מציג רק את מה שצריך לשבץ, ומפיק קובץ Word באותו מבנה כמו קובץ "משימות".

## איך עובדים עם זה

1. **קבצים** – גוררים את רשימת המדריכים (Excel, "נוער שוחר מדע - שיבוץ מדריכים") ואת קובץ הלו"ז (PDF, "קובץ לוז תשפ״ז" או כל שנה אחרת).
2. **מדריכים** – בודקים שהאתר הבין נכון מי מדריך/ה, מי קוסם/ת ומי מרצה, ואת אילוצי הזמינות (נקראים מעמודת "הערות"). מתקנים בלחיצה; התיקונים נשמרים גם כשמייבאים את הקובץ שוב.
3. **שיבוץ** – כל יום עיון/קורס מופיע ככרטיס, עם המשבצות שלו (הדרכה, הרצאה, מופע קסמים) והעמדות הפתוחות. לחיצה על עמדה פותחת רשימת מועמדים מסודרת:
   - קודם מי שמתאים/ה לתפקיד, פנוי/ה באותו יום ושעה ולא משובץ/ת במקביל;
   - בתוך זה – מי ששובצו הכי מעט החודש, ומי שעובדים הרבה עם בן/בת הזוג שכבר בקבוצה;
   - בנפרד: עם הסתייגות (שעות חלקיות, יום לא מועדף, הדרכת בטיחות חסרה), לא זמינים, ובלי התפקיד.
   - "שיבוץ אוטומטי של החסרים" ממלא את כל העמדות הפתוחות לפי אותם כללים (בכחול), ואפשר לבטל.
4. **ייצוא** – בוחרים חודש וחלקים (שובץ / לא שובץ / מדריכים שעוד לא שובצו / קורסים / הדרכות שבוצעו), מוסיפים "פערים לטיפול" ו"משימות", ומורידים Word או מעתיקים טקסט.

כשהלו"ז מתעדכן מייבאים אותו שוב: אירועים חדשים נוספים, והשיבוצים, ההערות והאירועים שהוסתרו נשמרים.

## מה נחשב רלוונטי

- **ימי עיון וקורסים** (כולל סביון, גלילאו, אורט נופים וכו'). תוכניות ספיר/שוהם/ענבר, מפגשי היערכות וכדומה מוסתרים (אפשר להציג אותם ב"הצג מוסתרים").
- בכל אירוע: **הדרכות** (מעבדות, ניסויים, קורסים – בדרך כלל זוג מדריכים לכל קבוצה), **הרצאות** ו**מופעי קסמים**.
- סינון לפי תחום: ברירת המחדל היא כימיה + כללי. ביולוגיה, מחשבים ואחר כבויים וניתן להדליק אותם.

## הרצה

אתר סטטי, בלי שרת ובלי התקנה. הנתונים נשמרים בדפדפן (או בחשבון claude.ai כשהאתר פתוח שם). בלשונית "קבצים" יש גיבוי ושחזור.

- **GitHub Pages**: Settings → Pages → Source: "Deploy from a branch" → בוחרים את הענף ואת התיקייה `/ (root)` → Save. אחרי דקה-שתיים האתר עולה בכתובת `https://<שם-המשתמש>.github.io/instructor-scheduling/`.
  - ב-GitHub החינמי, Pages עובד רק ל-repo ציבורי (ל-repo פרטי צריך GitHub Pro). אין בקוד נתונים אישיים: הקבצים שמייבאים נשארים בדפדפן של מי שמשתמש באתר ולא עולים ל-GitHub.
- **מקומית**: `npm start` (או `python3 -m http.server 8000`) ואז http://localhost:8000. פתיחה ישירה של `index.html` מהקובץ לא תעבוד, כי הדפדפן חוסם מודולים מ-`file://`.

## למפתחים

```
index.html            מבנה הדף
css/style.css         עיצוב
js/app.js             ממשק: לשוניות, כרטיסים, בחירת מדריכים, עורכים
js/pdf-grid.js        קריאת ה-PDF (pdf.js): תאים, תאריכים וצבעים לפי מבנה הלו"ז השבועי
js/schedule-parser.js מטקסט תא לאירוע: סוג, תחום, משבצות, קבוצות ועמדות
js/roster.js          קובץ המדריכים: תפקידים, בטיחות, ואילוצי זמינות מטקסט חופשי
js/names.js           השוואת שמות בעברית (היבה/היבא, בוצ'קו/בוצקו, שם אמצעי)
js/scheduling.js      מיזוג ייבוא חוזר, התנגשויות, דירוג מועמדים, שיבוץ אוטומטי
js/export.js          מסמך הייצוא (Word / טקסט / תצוגה)
js/storage.js         שמירה (localStorage או claude.ai) והורדת קבצים
js/demo.js            נתוני הדוגמה (שמות מומצאים)
vendor/               pdf.js 4.10.38 בסיומת .js (בקובץ ה-worker תווי בקרה בתוך מחרוזות הוחלפו ב-\xNN, אותה משמעות)
```

בדיקות: `npm test` (Node 20 ומעלה, בלי תלויות).

ספריות: pdf.js (בתיקיית vendor), ‏SheetJS ו-docx נטענות מ-CDN רק כשצריך אותן.
